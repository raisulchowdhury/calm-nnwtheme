    Special moves are shortcuts and patterns

    The same grammar shows up far outside the arcade. The first time you string a few moves together without touching the menus, the action collapses in time. Six trips become one fluid motion.

    Remember the motion

    The lesson is not that every shortcut should be memorized. The lesson is that good interfaces reward a rhythm that becomes easier to repeat.

    Developing your move set

    The way you build a move set is the same way the arcade kids built theirs. You try things. You fail a lot. You watch people who are better than you and steal what they do.

    Mastery without mashing buttons

    Every fighting game player started by mashing buttons. Random inputs, hoping a fireball would come out, occasionally winning by accident. Mashing is how you find the inputs in the first place. The part that actually matters is noticing which inputs worked, like pressing ↓ ↘ → P on purpose the second time.
