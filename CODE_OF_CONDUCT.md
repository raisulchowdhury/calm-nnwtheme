# Code of Conduct

Calm's community should feel as considered as the reading surface itself.

## Expected behavior

- Be respectful, specific, and constructive.
- Critique the work, not the person.
- Make room for different levels of experience and different accessibility
  needs.
- Protect private information shared in bug reports or security disclosures.

Harassment, discrimination, threats, deliberate disruption, and publishing
another person's private information are not acceptable.

## Scope and enforcement

This code applies in the repository and in project-related public
conversations. Maintainers may edit or remove contributions that violate it and
may temporarily or permanently restrict participation.

For conduct that occurs on GitHub, use GitHub's private
[reporting tools](https://support.github.com/contact/report-abuse). Security
issues should follow [SECURITY.md](SECURITY.md).
